# Galaxy Black Hole Simulator

A Real-Time Black Hole Gravity Simulation Built Using Python and Pygame

Gravity Simulation • Galaxy Visualization • Particle Physics • Space Ambience

---

## Project Overview

Galaxy Black Hole Simulator is a real-time physics-inspired visualization project that demonstrates how a black hole interacts with nearby celestial objects through gravitational attraction.

The simulator creates a dynamic galaxy environment where hundreds of stars and particles move under the influence of a black hole. As particles enter the event horizon, they are absorbed, causing the black hole to grow in mass and size.

This project was developed to explore simulation programming, object-oriented design, particle systems, real-time rendering, and interactive visual effects using Python and Pygame.
